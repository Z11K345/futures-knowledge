银期签约

在银行端完成银期签约后，即可在广发期货账户与本人银行卡之间划转资金。
← 返回知识库首页
签办理银期签约时间
期货交易日（日盘）8:30-16:00
期货交易日（夜盘）20:30-2:30
上述时间以期货交易日为准；非交易时段银行端不受理签约。
注意：工商银行、建设银行不支持夜盘时段签约，请在这两家的日盘时间办理。

操作位置：在您所用银行的手机银行 APP 里搜索「银期」或「期货」即可进入；选择期货公司时请选「广发期货有限公司」。

叫法对应：银行页面提到的「保证金账户 / 资金账户」就是您的期货资金账号（如 999XXXXXX）；「保证金密码 / 资金密码」就是您的期货资金密码。部分银行还会要求输入银行卡取款密码及银行预留手机收到的验证码，请用本人预留手机办理。

支持手机银行办理的银行点击银行名展开步骤
中 中国银行 手机银行自助办理 · 共 4 步 手机银行
  1. 1登陆中国银行手机银行，在手机银行首页的上方搜索栏输入“银期服务”后点击搜索；
  2. 2点击进入“银期服务”功能；
  3. 3点击“签约”；
  4. 4选择期货公司后，输入客户个人详细信息，阅读协议后，点击“确认”即可完成签约。

工 工商银行 手机银行自助办理 · 共 6 步 手机银行
  1. 1点击图标，进入工行手机银行；
  2. 2点击登陆，输入手机银行账号、密码；
  3. 3在最上方搜索栏输入“期货”，然后搜索，点击进入功能“期货” ；
  4. 4签约选择“集中式银期转账注册”；
  5. 5选择期货公司；
  6. 6输入期货资金账号，选择要签约银行卡，勾选同意协议，按提示完成操作；
该行不支持夜盘时段签约，请在日盘时间办理。

建 建设银行 手机银行自助办理 · 共 5 步 手机银行
  1. 1登陆建设银行手机银行，然后在首页上方搜索栏输入“银期”后搜索。
  2. 2选择功能证券期货。
  3. 3点击下方，“立即签约”选项。
  4. 4搜索签约公司-广发期货有限公司。
  5. 5输入期货公司的客户号和资金密码后点击下一步即可开通业务。
该行不支持夜盘时段签约，请在日盘时间办理。

农 农业银行 手机银行自助办理 · 共 3 步 手机银行

  2. 2然后点击“银期转账签约”；
  3. 3选择银行账户和期货公司，输入期货资金账号和密码，勾选接受协议后提交签约。

交 交通银行 手机银行自助办理 · 共 4 步 手机银行
  1. 1登陆交通银行手机银行，然后点击首页右上方的搜索图标，输入“期货”后搜索，再点击功能期货。
  2. 2点击 “银期签约管理”。
  3. 3点击 “办理新的银期转账签约”。
  4. 4最后输入详细信息，点击“下一步”即可完成签约。
注：1、签约期货账户，期货公司请选择“广发期货有限公司 ”；2、签约股票期权账户，期货公司请选择“广发期货有限公司（银衍）” ；3、签约股票期权现货账户，期货公司请选择“广发期货有限公司（证券现货）” 。

招 招商银行 手机银行自助办理 · 共 5 步 手机银行

  2. 2点击进入“银期转账”；
  3. 3点击进入“建立协议”；
  4. 4选择期货公司；
  5. 5输入身份证号、保证金账号（客户号）、保证金密码（交易密码）、取款密码（银行卡密码），勾选“期货端转账控制”两选项，勾选“已读阅并同意协议条款”。
（注意事项：办理时会向该银行卡预留手机号码发送验证码，因此最好使用预留的手机登陆手机银行或者携带有预留的手机）
